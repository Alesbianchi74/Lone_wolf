# Lone Wolf Companion

An unofficial, fan-made companion app for playing the Lone Wolf gamebooks by Joe Dever, books 1 to 12 (Italian edition). It replaces the paper Action Chart and the Random Number Table.

- Character sheet with Disciplines, ranks, Lore-circles and automatic bonuses
- Inventory with weapons, backpack, special items and armour compatibility
- Combat with the extended Combat Results Table and an animated random number reel
- Journal of sections, fights and notes
- Rules summary and personal book maps

Installable on iPhone and Android as a Progressive Web App and usable offline. Game data stays on the device; backups can be exported as JSON files.
